# 培训考试平台 — 需求规格书

> 状态：已确认（Phase 1 产出）
> 日期：2026-08-20
> 范围：分部门/专业的企业内部培训答题系统，含用户端与管理端
> 参考项目：`/home/jinan/PythonProj/HCIP-CC`（仅作答题 UX 与题型 schema 蓝本，不迁移题库）

---

## 1. 项目背景与目标

为企业内部培训提供一套轻量级答题/考试系统。按部门与专业对员工进行分组，支持多模式练习与考试，管理端可管理用户、题库、考试与系统配置。

- **目标用户规模**：≤ 100 人。
- **题库规模**：≤ 10 万题。
- **轻量化**：单进程 + 单 SQLite 文件，一键启动。
- 新项目空题库起步，**不迁移** HCIP-CC 任何题目数据。

## 2. 目标用户与场景

| 角色 | 场景 |
|---|---|
| 普通用户 | 邮箱注册→激活→登录→练习/考试→查看个人面板与进度 |
| 部门管理员 | 管理本部门用户、题库、发布考试、查看本部门排行 |
| 超级管理员 | 全局用户/题库/考试/系统设置、查看全维度排行 |

## 3. 角色与权限

- **普通用户**：仅可答题、查看个人数据。
- **部门管理员**：管理本部门（部门管理员所属部门及其子分组）用户与题库、发布面向本部门的考试、查看本部门维度排行。
- **超级管理员**：全局管理权限，含系统设置。

## 4. 核心功能清单

### 4.1 账号与认证（P0）
- 邮箱 + 密码注册，邮箱验证码激活（依赖 SMTP 配置）。
- 支持自助注册；管理员可审批/禁用用户。
- JWT 登录，Token 过期重登。

### 4.2 组织与分组（P0）
- 单张 `groups` 表，`type ∈ {部门, 专业, 班级, 自定义}`，支持父子层级（`parent_id`）。
- 用户↔分组多对多（一个用户可属多个分组）。
- 授权"哪些分组可做某题库/考试"直接用 `group_id` 集合关联。

### 4.3 题库管理（管理端 P0）
- **6 类题型**：单选、多选、判断、填空、简答、拖拽。沿用 HCIP-CC `type` 字段语义；`answer` 前 5 类为字符串、拖拽为映射对象，SQLite 用 JSON 列承载。
- **判分规则**：多选/拖拽全对才对、无部分分；填空大小写不敏感；简答自评 / 正式考试人工复核。
- **题目字段**：题干、选项/空位、答案、解析、难度(1–3)、知识点标签、分值、题库来源(`bank`)、所属分组。
- **Excel 模板上传**：`.xlsx`，每题型一个 Sheet，扁平中文表头，便于豆包/DeepSeek 等 LLM 批量转换 Word 题库；导入预览 + 错误报告；附"说明"Sheet 与转换 Prompt 草稿。
  - 填空题：空位答案按顺序用 `|` 分隔，每空多等价答案用 `/` 分隔。
- **题目编辑**：单题增删改查，支持按分组/标签/题型筛选。

### 4.4 答题模式（用户端 P0）
- 顺序答题、按题型、随机抽题、错题本、模拟考试、正式考试。
- **实时保存**：练习逐题写入服务端；考试建会话表逐题更新、交卷结算。**不做离线补传。**
- 复用 HCIP-CC 答题 UX：题目导航网格、选项着色、简答自评交互、拖拽交互、顺序练习进度恢复、考试选项打乱、计时最后 10 分钟变红。

### 4.5 考试（P0）
- **模拟考试**：用户自助开考，套用管理员配置的默认规则；题型含 5 类客观题（单选/多选/判断/填空/拖拽）+ 简答（自评）；规则在管理页可配（题数/题型配比/限时/及格线/是否回显答案）；练习性，不计正式档案。
- **正式考试**：管理员发布、指派分组、单场配规则。规则项：开放起止时间、限时、题数与组卷方式（手选/规则抽题）、及格线、最大尝试次数、交卷后是否立即出分、是否回显答案与解析、简答是否人工复核。正式成绩进排行/档案，含简答时成绩待复核后公布。
- **规则组卷（自动生成试题）**：题数、各题型配比、难度配比、来源题库（按分组/标签筛选，不按标签加权）、每题分值、是否允许重复抽题、随机种子、总题数上限；生成后落为试卷模板→预览题目→选择指派分组→发布。

### 4.6 面板与排行（P0）
- **用户端面板**：累计答题数、总正确率、已练/题库总量（覆盖率）、错题数、模拟考试平均分、正式考试最高分；顺序练习进度条、各题型掌握雷达图；最近考试记录、待办（未完成指派考试、待复核简答）；快捷入口。无打卡/学习时长指标。
- **管理端面板**：考试完成率、平均正确率、注册/活跃用户数、题库总量、待复核简答题数；待办（待发布考试、待复核简答、待审批用户、上传进度）。
- **排行**：部门/专业/分组/个人 四维度 × 正确率/完成率/累计答题数/考试平均分 × 时间范围（今日/本周/本月/全部）。不导出 Excel。

### 4.7 系统管理（P0/P1）
- **P0**：SMTP（主机/端口/账号/密码/发件人/是否 TLS）、注册开关、新用户是否需��批、站点名称与 Logo、默认及格线、默认考试限时、单场考试最大题数、题库上传大小/格式限制、邮件模板（注册验证、考试通知）。
- **P1（可选）**：密码策略、会话超时、数据备份导出。

## 5. 业务规则与约束

1. 正式考试成绩含简答时，须待管理员人工复核后公布。
2. 多选/拖拽无部分分；填空大小写不敏感。
3. 考试选项打乱后判分须用打乱后的 `newAnswer` 比对（沿用 HCIP-CC 机制）。
4. 进度实时落库，不做离线补传。
5. 题库 ID 跨题库来源可能冲突，须用 `bank` 维度隔离（预留，当前空题库）。
6. 单场正式考试最大尝试次数由规则项决定。

## 6. 非功能需求

- **性能**：<100 用户、<10 万题；SQLite 单文件足够；排行查询需建索引。
- **部署**：单进程 `./start.sh`（构建前端 + `uv run uvicorn`），访问 `http://localhost:8000`。
- **安全**：输入校验、SQL 注入防护（ORM 参数化）、XSS 防护、密码哈希（bcrypt）、JWT 鉴权、敏感数据（SMTP 密码等）加密存储。
- **可维护**：遵循 PEP 8 + Google Python Style Guide；前端 ESLint 严格模式 + Prettier。

## 7. 技术栈

- **后端**：Python 3.10+ / FastAPI / SQLAlchemy / SQLite3；`uv` 管理依赖；强制虚拟环境 `.venv`。
- **前端**：Vue 3（Composition API）/ TypeScript 5.x / Element Plus / Vite；`pnpm` 管理依赖。

## 9. 验收标准

- 邮箱注册→验证码激活→登录全流程可用。
- 用户可按 6 种模式答题，进度实时保存，刷新不丢。
- 管理员可上传 Excel 题库并预览/报错，可编辑单题。
- 管理员可配置模拟考试规则、发布正式考试指派分组，用户可参加并出分（含简答复核流程）。
- 规则组卷可按配置自动生成试卷并指派。
- 双端面板指标与排行四维度切换正常。
- SMTP 配置后邮件可正常发送（注册验证码、考试通知）。
- `./start.sh` 一键启动，`http://localhost:8000` 可访问。

- 填空答案按空位顺序用 `|` 分隔，每空多等价答案用 `/` 分隔。
