# 培训考试平台 — UI/UX 规范

> 状态：已确认（Phase 2 产出）
> 依据：`docs/requirement.md`
> 组件库：Element Plus 5.x（Vue 3 Composition API + TypeScript）

---

## 1. 全局视觉规范

### 1.1 主题与品牌色
- **品牌主题色可配置**：超级管理员在「系统管理 → 基础设置」配置站点主色（HEX），前端通过 CSS 变量 `--brand-primary` 动态注入，Element Plus 主题跟随。
- 默认主色 `#E60012`（联通红），可切为任意 HEX；并提供「浅/深」两个预设。
- 背景浅灰 `#F5F7FA`，卡片白底 `#FFFFFF` + 轻阴影；暗色模式列为 P1。
- 站点 Logo 与站点名称同样在基础设置配置，顶栏左侧展示。

### 1.2 布局
- 整体上下两层：**顶栏（60px）+ 主体区**。
- 用户端主体为「左侧导航（200px，可折叠）+ 内容区」。
- 管理端主体为「左侧管理菜单（220px，可折叠）+ 内容区」。
- 内容区统一最大宽度 1200px 居中，卡片间距 16px，内边距 24px。
- 响应式：≤992px 左侧导航折叠为抽屉（Hamburger 触发）。

### 1.3 字体与间距
- 字体族：`PingFang SC, Microsoft YaHei, Helvetica, Arial`；正文 14px、标题 16–20px、统计卡数字 28–32px。
- 间距梯子：4 / 8 / 12 / 16 / 24 / 32px。

## 2. 角色与入口

### 2.1 单应用角色分流
- 同一 Vue 应用、同一登录页；登录后按角色路由分流：
  - 普通用户 → 用户端布局（只见用户端导航）。
  - 部门管理员 → 用户端 + 顶栏出现「管理后台」入口，管理端仅限本部门范围。
  - 超级管理员 → 用户端 + 「管理后台」入口，管理端全权限。
- 无管理权限时「管理后台」入口隐藏。管理员在管理端可通过顶栏「返回用户端」切换。

### 2.2 路由分区
- 用户端：`/`、`/exam`、`/wrong`、`/marks`、`/rank`、`/profile`、`/answer/:mode`。
- 管理端：`/admin`、`/admin/users`、`/admin/groups`、`/admin/questions`、`/admin/upload`、`/admin/exam-templates`、`/admin/mock-config`、`/admin/exams`、`/admin/exam-records`、`/admin/review`、`/admin/settings`、`/admin/audit`。

## 3. 用户端页面结构

### 3.1 顶部导航
```
[Logo 站点名] [首页] [答题] [考试] [错题本] [我的标记] [排行]          [▾个人信息|退出]
管理权限角色额外显示 [管理后台]
```

### 3.2 首页面板
- **统计卡行**（4 卡）：累计答题数 / 总正确率 / 覆盖率(已练/题库总量) / 错题数。
- **次级卡行**：模拟考试平均分、正式考试最高分。
- **进度区**：顺序练习进度条；各题型掌握雷达图（6 题型轴，正确率%）。
- **待办区**：未完成指派考试（可点击进入）、待复核简答题条数（正式考试含简答未复核）。
- **快捷入口**：继续练习 / 参加考试 / 我的错题。
- **最近记录**：最近 5 条模拟/正式考试（日期、类型、分数、是否及格）。

### 3.3 答题模块
- **模式选择页**：6 个卡片入口——顺序练习 / 按题型（展开题型选择）/ 随机抽题 / 错题本 / 我的标记 / 模拟考试。
  > 注：错题本、我的标记、模拟考试虽各有专属顶栏入口，但在「答题」模块内也并列展示，便于一站式访问。
- **答题页**（核心，见第 4 节）。
- **顺序练习进度恢复**：进入顺序练习若有上次进度，弹窗「是否从第 N 题继续？」。

### 3.4 考试模块
- 卡片列表展示当前可参加的模拟/正式考试：标题、类型、限时、开放时段（正式）、状态（未开始/进行中/已结束/待复核）、操作（进入考试/查看成绩）。
- 点击「进入考试」→ 考前须知弹窗（规则摘要：题数、限时、及格线、是否回显）→ 确认开始。

### 3.5 错题本
- 错题列表（题号、题型、题干预览、我的上次答案、错误时间），支持按题型/标签筛选，操作：重做、移除。
- 重做走答题页单题流程；掌握后自动移出错题本（见 6.4）。

### 3.6 我的标记（独立入口）
- 用户主动标记的题目列表，与错题本逻辑解耦：题号、题型、题干预览、标记时间、备注。
- 操作：跳转答题、取消标记。

### 3.7 排行榜
- **Tab 切换维度**：部门 / 专业 / 分组 / 个人。
- **指标**（列选择器）：正确率 / 完成率 / 累计答题数 / 考试平均分。
- **时间范围**：今日 / 本周 / 本月 / 全部。
- **呈现**：表格列表（排名、名称、指标值）+ 右侧 Top10 柱状图（跟随当前指标）。柱状图配色遵循品牌主色梯度。

## 4. 答题页核心交互（三栏）

### 4.1 布局
```
┌──────────┬───────────────────────────┬──────────┐
│ 导航网格  │  题目区                     │ (窄)      │
│ 题号方格  │  题干 + 选项/填空/拖拽       │          │
│ (折叠抽屉)│  提交后：选项着色 + 解析      │          │
│          │                             │          │
│          │  底部：上一题 | 标记 | 下一题/提交│          │
│          │  考试：倒计时               │          │
└──────────┴───────────────────────────┴──────────┘
```
- 移动端：导航网格折叠为右上抽屉按钮。

### 4.2 导航网格（题号方格）
- 每题一格，颜色编码：

| 状态 | 颜色 | 说明 |
|---|---|---|
| 未答 | 灰底 | 默认 |
| 已答(练习) | 绿底(对)/红底(错) | 提交即时判分 |
| 已答(考试) | 蓝底 | 仅记录不判分 |
| 当前题 | 蓝边框高亮 | |
| 已标记 | 黄角标 | 主动标记 |
| 已掌握 | 浅绿底 | 简答自评或错题重做掌握 |

- 点击跳转；支持「标记/取消标记」按钮。

### 4.3 题型交互
- **单选/多选**：选项卡片，单选 radio、多选 checkbox；提交后正确项绿、错选项红、应选未选黄描边。
- **判断**：正确/错误两按钮；着色同单选。
- **填空**：行内输入框（按空位数量生成），提交逐空判分，每空标对错，错空旁显示正确答案。
- **简答**：文本域；练习/模拟提交后显示参考答案 + 「掌握」「需复习」自评按钮（隐藏提交按钮）；正式考试显示纯文本框，交卷后等待复核，不显示参考答案。
- **拖拽**：左侧可拖概念条 + 右侧放置区（沿用 HCIP-CC HTML5 drag + 触屏 polyfill + 点击移除）；提交逐对判分，对错着色连线。

### 4.4 底部操作栏
- 练习：`上一题 | 标记 | 下一题 | 提交当前题`
- 考试：`上一题 | 标记 | 下一题 | 交卷`，右上方固定倒计时（最后 10 分钟变红、最后 1 分钟闪烁）。到点自动交卷。

## 5. 管理端页面结构

### 5.1 左侧菜单
```
概览面板
用户管理
  ├ 用户列表
  └ 分组管理（树形：部门/专业/班级/自定义，父子层级）
题库管理
  ├ 题目列表
  ├ 上传题库
  └ 试卷模板（规则组卷结果）
考试管理
  ├ 模拟考试设置（默认规则）
  ├ 正式考试（发布/指派/复核）
  └ 考试记录（成绩/档案）
系统管理
  ├ 基础设置
  ├ 邮件 SMTP
  ├ 注册与审批
  └ 审计日志
```

### 5.2 概览面板
- 统计卡：考试完成率 / 平均正确率 / 注册用户数 / 活跃用户数 / 题库总量 / 待复核简答题数。
- 排行区（默认按部门·正确率·本月）。
- 待办：待发布考试 / 待复核简答 / 待审批用户 / 题库上传进度。

### 5.3 用户管理
- **用户列表**：表格（邮箱、姓名、角色、所属分组、状态、注册时间），操作：编辑、审批、禁用/启用、重置密码、分配分组。搜索 + 按分组/角色筛选 + 分页。
- **分组管理**：树形展示分组，节点操作：新增子分组、编辑、删除、拖拽排序；新建时选 `type`。

### 5.4 题库管理
- **题目列表**：表格（题号、题型、题干预览、分组、标签、难度、来源），筛选（题型/分组/标签/难度/来源），操作：编辑、删除、查看作答统计。分页。
- **上传题库**：步骤式（见第 7 节）。
- **试卷模板**：规则组卷生成的试卷模板列表，可预览题目清单、指派分组、发布为考试。

### 5.5 考试管理
- **模拟考试设置**：表单配置默认规则（题数、各题型配比、难度配比、来源题库筛选、分值、限时、及格线、是否回显答案）。
- **正式考试**：考试卡片列表（草稿/待发布/进行中/已结束/待复核），新建/编辑考试规则表单 + 指派分组，发布、复核入口。
- **考试记录**：按考试筛选的成绩档案表格。
- **简答复核**：待复核简答题列表，逐题展示题干、用户答案、参考答案，操作：判为「通过」/「不通过」/「部分分」；全部复核完成→公布成绩。

### 5.6 系统管理
- **基础设置**：站点名称、Logo、主题色、默认及格线、默认考试限时、单场最大题数、上传大小/格式限制。
- **邮件 SMTP**：主机/端口/账号/密码/发件人/是否 TLS，含「发送测试邮件」按钮。
- **注册与审批**：注册开关、新用户是否需审批、待审批用户列表。
- **审计日志**：管理员关键操作记录（操作人、时间、操作类型、对象、详情），按时间/操作人/类型筛选。

## 6. 组件状态定义

### 6.1 统一按钮状态
`默认 → 悬停(hover，主色浅一档) → 点击(active，主色深一档) → 加载中(loading 图标+禁用) → 禁用(灰)`。

### 6.2 表格行状态
`默认 → 悬停(浅灰底) → 选中(品牌色浅底) → 禁用(灰字)`。

### 6.3 卡片状态
`默认 → 悬停(阴影加深 + 上移 2px) → 选中(品牌色边框)`。

### 6.4 简答「掌握」流转
- 练习/模拟中简答点「掌握」→ 该题加入 `correct`，若原在错题本则**自动移出错题本**；点「需复习」→ 加入错题本。
- 正式考试简答不在此流程，走人工复核。

### 6.5 倒计时
- 正常：品牌色数字；最后 10 分钟：红色；最后 1 分钟：红色闪烁；到点：弹窗「时间到，已自动交卷」→ 结算。

## 7. 题库上传交互流程（步骤式）

1. **下载模板**：按钮下载 `.xlsx`（含说明 Sheet 与转换 Prompt 草稿）。
2. **选择所属分组 / 题库来源(bank)**：上传前下拉选择，作为本次导入批量归属。
3. **上传文件**：拖拽/选择 → 后端解析 → 返回**预览**（前 20 题表格 + 总数 + 各题型分布）。
4. **错误报告**（若有）：逐行错误清单（行号 + 原因），可下载错误清单修正重传。
5. **确认导入**：进度条 → 完成提示成功题数与失败题数。

## 8. 表单校验与反馈规范

- **行内校验**：注册/登录/题目录入/考试配置等表单，失焦即校验，错误红框 + 下方提示文字。
- **提交校验**：提交时汇总未通过项，聚焦首个错误字段，顶部红色 Alert。
- **操作反馈**：成功绿色 `ElMessage`、失败红色 `ElMessage`；删除、发布、禁用等危险操作 `ElMessageBox` 二次确认。
- **加载态**：列表/表格 `v-loading`，按钮 loading 图标，页面级 `v-loading` 用于考试结算、导入处理。
- **草稿自动保存**：题目录入、考试配置等长表单每 10s 自动存草稿（localStorage），离开页面前若有未保存改动弹窗提示「保存草稿/丢弃」。

## 9. 错误页与空状态

- **404/403/500**：统一错误页（图标 + 文案 + 返回首页按钮），403 额外提示「无权限访问该管理功能」。
- **空状态**：列表无数据展示 `el-empty`（如题库为空、暂无考试、暂无错题）+ 引导操作按钮。
